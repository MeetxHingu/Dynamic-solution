## 🚀 Overview

**Dynamic Automations** is a modern software and web development agency platform engineered for local businesses and international clients. It provides high-performance web architecture, automated WhatsApp customer inquiry bots, rapid website bug fixing, and annual maintenance contracts (AMC).

### Key Features
- **Verified Revenue & Invoices Ledger**: Transparent audit ledger tracking production milestones and delivered client deliverables (including Santram Hospital, Kapdadiya Priyanka, and Bhargav Patel).
- **Interactive Project Scope & Cost Estimator**: Real-time dual-currency calculator supporting Indian Rupees (₹) and US Dollars ($) with transparent 50% advance / 50% live delivery milestone pricing.
- **Free SEO & Web Health Audit Tool**: High-converting client diagnostic utility testing Core Web Vitals, Schema.org readiness, mobile responsiveness, and 1-click WhatsApp lead integration.
- **Local SEO & Knowledge Hub**: Guides and structured data (`LocalBusiness`, `FAQPage`, `ProfessionalService` JSON-LD) optimized for regional Gujarat search queries and international remote clients.
- **Founder Admin Portal & Inquiries DB**: Password-protected lead management dashboard allowing real-time inquiry status tracking (`New` -> `In Progress` -> `Completed`), 1-click WhatsApp messaging, internal notes, and instant CSV/Excel export.

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS, Lucide React Icons
- **Data Architecture**: Structured JSON-LD metadata, persistent client-side database with reactive event synchronization
- **Production Build**: Vite + Node.js (Cloud Run compatible)

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/your-username/dynamic-automations.git

# Navigate into the project folder
cd dynamic-automations

# Install dependencies
npm install

# Start the local development server
npm run dev
```

Visit `http://localhost:3000` in your browser.
